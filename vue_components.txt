# 组件基础

组件使开发者能够将用户界面拆分成独立且可复用的模块，便于单独处理。实际开发中，这些模块通常呈现为嵌套的树形层级。Vue 提供了自身的组件模型，允许在内部封装自定义逻辑与内容。

## 定义一个组件

在使用构建工具的场景下，Vue 组件通常被编写于独立的 .vue 文件内，此类文件被称为单文件组件（SFC）：

<script setup>
import { ref } from 'vue'
const count = ref(0)
</script>

<template>
  <button @click="count++">You clicked me {{ count }} times.</button>
</template>

若不使用构建工具，组件则通过包含 Vue 特定配置的 JS 对象来定义：

export default {
  data() {
    return { count: 0 }
  },
  template: `<button @click="count++">You clicked me {{ count }} times.</button>`
}

## 使用组件

若要在父组件中使用子组件，必须先将其导入。例如将计数器组件置于 ButtonCounter.vue 中：

<script>
import ButtonCounter from './ButtonCounter.vue'
export default {
  components: { ButtonCounter }
}
</script>

<template>
  <h1>Here is a child component!</h1>
  <ButtonCounter />
</template>

使用 <script setup> 时，导入的组件可直接在模板中使用。组件支持无限次复用，每次使用组件都会创建一个新实例，各组件维护独立的状态。

在 SFC 中，建议子组件标签名采用 PascalCase 以区分原生 HTML 元素。若直接在 DOM 中编写模板，需使用 kebab-case 并显式闭合标签。

## 传递 props

Props 是特殊的 attributes，需在组件上声明注册。传递数据时，必须在 props 列表中声明：

<script>
export default {
  props: ['title']
}
</script>

<template>
  <h4>{{ title }}</h4>
</template>

使用 <script setup> 时，通过 defineProps 宏声明：

<script setup>
defineProps(['title'])
</script>

defineProps 是 <script setup> 专属的编译宏，无需导入，声明的 props 自动暴露给模板。

组件可拥有任意数量的 props。实际应用中，可用 v-for 渲染列表：

<BlogPost
  v-for="post in posts"
  :key="post.id"
  :title="post.title"
/>

注意使用 v-bind 语法（:title）传递动态 prop 值。

## 监听事件

组件可通过自定义事件与父组件交互。父组件通过 v-on 或 @ 监听子组件抛出的事件：

<BlogPost @enlarge-text="postFontSize += 0.1" />

子组件通过调用内置 $emit 方法并传入事件名来触发事件：

<template>
  <div class="blog-post">
    <h4>{{ title }}</h4>
    <button @click="$emit('enlarge-text')">Enlarge text</button>
  </div>
</template>

可通过 emits 选项或 defineEmits 宏声明需抛出的事件：

<script setup>
defineEmits(['enlarge-text'])
</script>

## 通过插槽来分配内容

某些场景下，需像 HTML 元素一样向组件传递内容：

<AlertBox>
  Something bad happened.
</AlertBox>

这可通过 Vue 的 <slot> 元素实现：

<template>
  <div class="alert-box">
    <strong>This is an Error for Demo Purposes</strong>
    <slot />
  </div>
</template>

<slot> 作为占位符，父组件传入的内容将在此处渲染。

## 动态组件

某些场景需在多个组件间切换，如 Tab 界面。这可通过 Vue 的 <component> 元素及特殊的 is attribute 实现：

<component :is="currentTab"></component>

传给 :is 的值可以是注册的组件名或导入的组件对象。使用 <component :is="..."> 切换组件时，被切换的组件会被卸载。可通过 <KeepAlive> 组件保持其存活状态。

## DOM 内模板解析注意事项

### 大小写区分

HTML 标签和属性名不区分大小写，浏览器会将大写转为小写。因此在 DOM 内模板中，PascalCase 组件名、camelCase prop 名及 v-on 事件名均需转换为 kebab-case 形式。

### 闭合标签

在 DOM 内模板中，必须显式写出关闭标签，因为 HTML 仅允许少数特殊元素省略闭合标签。

### 元素位置限制

某些 HTML 元素（如 <ul>、<table>）对子元素类型有限制。解决方案是使用特殊的 is attribute：

<table>
  <tr is="vue:blog-post-row"></tr>
</table>

注意，在原生 HTML 元素上使用 is 时，值必须加 vue: 前缀。
